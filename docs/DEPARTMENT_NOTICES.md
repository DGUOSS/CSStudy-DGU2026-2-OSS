# 관심 학과 공지

학교 공통 학사공지와 사용자가 즐겨찾은 학과 공지를 메인 화면에서 확인한다.

## 사용법
- 로그인 후 메인의 **관심 학과 설정**에서 학과/단과대학 이름으로 검색하고 최대 8개를 저장한다.
- 전체 탭은 각 게시판 첫 페이지를 날짜순으로 합친다. 전체 게시물을 통합 페이지 처리하는 기능은 아니다.
- 학교/학과 탭에서는 해당 게시판의 이전 페이지까지 조회하고 제목·본문을 검색할 수 있다.
- 본문은 텍스트만 표시한다. 이미지, 표, 첨부파일은 원문에서 확인한다.
- 즐겨찾기는 계정에 저장하며, 수강 인증이나 강좌 접근 권한에는 영향을 주지 않는다.

## 범위와 예외
2026-11-18 동국대학교 대학 안내(https://www.dongguk.edu/page/853) 기준 62개 항목을 등록했다. 60개 공개 목록을 확인했으며 스포츠문화학과, 지능IoT학과는 게시판 미확인으로 선택할 수 없다. WISE캠퍼스와 대학원은 포함하지 않는다.

원본 목록은 backend/app/features/department_notices/catalog.json이다. 학과와 게시판 출처를 별도로 정의하므로 향후 공동 게시판도 연결할 수 있다. URL은 검토된 카탈로그만 사용하며 사용자가 임의 URL을 입력할 수 없다.

영화영상학과의 일부 본문은 해당 사이트 로그인이 필요하다. 이런 본문은 수집하지 않고 원문 이용을 안내한다. 날짜에 연도가 없는 게시물은 날짜를 추정하지 않는다. 학교 사이트 구조 변경, 장애가 있으면 일부 출처만 실패할 수 있다.

## API
기본 경로: /api/v1/department-notices
- GET /catalog: 학과 목록 (공개)
- GET /preferences: 본인의 즐겨찾기
- PUT /preferences: department_ids 배열 저장 (최대 8개)
- GET /feed?source=all&q=&page=1: 합친 목록. source는 school 또는 즐겨찾기 학과의 source ID. 개별 출처에서는 페이지 조회 가능.
- GET /sources/{source_id}/items/{notice_id}?q=&page=1: 현재 조회 목록에 포함된 공지 본문

카탈로그 외 API는 로그인이 필요하다. 사용자별 데이터는 CurrentUser로 제한한다. 출처별 캐시는 10분, 실패 재시도 간격은 1분이며 장애 시 최대 24시간 전 캐시를 표시하고 오래된 목록임을 안내한다. 외부 요청 동시 실행은 8개로 제한한다. 프로세스 메모리 캐시이므로 재시작하면 초기화된다.

## DB 반영
notice_preferences 테이블 하나를 추가한다. user_id는 users.id 외래키이자 기본키이며 department_ids는 JSON 배열이다. 기존 테이블 데이터는 수정하지 않는다.

마이그레이션: e5b7d9f1a3c2 → a90dc6c4db81. 배포 환경에서 백엔드를 시작하기 전에 `alembic upgrade head`가 필요하다. 개발 검증은 임시 SQLite에서만 수행했다. 운영 Neon에는 적용하지 않았다.

## 검증
자동 테스트는 사용자 간 설정 분리, 인증/입력 검증, 부분 장애, 출처별 ID 중복, 검색·페이지 파싱, 본문 텍스트 처리와 알려지지 않은 공지 차단을 다룬다. 외부 사이트 요청은 자동 테스트에서 모의 처리한다. 실제 60개 학과 목록과 대표 형식의 검색/2페이지 조회는 별도로 확인했다.
