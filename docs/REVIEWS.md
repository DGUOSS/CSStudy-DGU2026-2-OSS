# 강좌 후기

강좌 페이지의 `강좌 후기` 탭에서 수강 학기, 전체 추천도, 체감 난이도, 과제량, 본문을 입력한다.

- 추천도: 클릭 가능한 별 1~5개. 별이 많을수록 추천한다.
- 난이도: 클릭 가능한 별 1~5개. 별이 많을수록 어렵다.
- 과제량: 매우 적음 / 적음 / 보통 / 많음 / 매우 많음 중 하나를 고른다(1~5 저장).
- 본문: 앞뒤 공백 제거 후 10~3000자.

## 권한과 작성 제한

- 로그인한 사용자는 강좌 찾기에서 수강 기록 없이 과목·교수별 후기를 읽을 수 있다. 최신 작성순으로 20개씩 표시한다.
- 작성 시 수강 기록의 소유자와 연결된 강좌를 서버에서 확인한다. 관리자·공용 강좌 접근 권한만으로 작성할 수 없다.
- 사용자·강좌(course_id, 과목+교수)당 한 번만 작성한다. 교수가 다르면 각각 작성할 수 있지만 같은 교수의 강좌는 학기·분반이 달라도 중복 작성할 수 없다. 후기는 선택한 교수의 강좌에 표시한다.
- 수강 학기는 본인의 기록 중 선택하며 서버가 해당 기록에서 확정한다.
- 저장 후 내용·점수·학기를 수정할 수 없다. 수정 화면과 PATCH API는 제공하지 않는다.
- 본인 후기를 삭제할 수 있다. 삭제 시 본문을 비우고 목록에서 숨기지만 작성 이력은 남겨 재작성을 막는다. 점수는 숨김 기록에 남으며 공개 목록에 반환하지 않는다.
- DB의 사용자·강좌 고유 제약으로 동시 중복 요청도 막는다.
- API 응답에는 작성자 이름·이메일·사용자 ID·수강 기록 ID를 반환하지 않는다. DB에는 작성자가 저장되므로 운영자까지 포함한 완전 익명은 아니다.
- 엔드림스 수강 기록 연결을 이용하며 학교가 발급하는 수강 인증은 아니다.
- 관리자가 강좌를 삭제하면 해당 강좌의 후기와 작성 이력도 함께 제거된다.
- 신고·관리자 숨김, 댓글, 시험 유형 구조화, 학기별 필터는 포함하지 않는다.

## API

| 메서드 | 경로(`/api/v1`) | 용도 |
|---|---|---|
| GET | `/courses/{id}/reviews/terms` | 본인 수강 학기와 해당 강좌의 기존 후기 ID(삭제 이력 포함) |
| GET | `/courses/{id}/reviews?offset=0&limit=20` | 삭제되지 않은 익명 후기 목록 |
| POST | `/courses/{id}/reviews` | 후기 작성 |
| DELETE | `/reviews/{id}` | 본인 후기 본문 삭제 및 숨김 |

## DB 적용

`course_reviews`는 아직 커밋·배포하지 않은 `a4c9e2b710df` 마이그레이션에 정의한다. 초기 구현을 수정해 `recommendation`, `is_deleted`를 포함하고 사용자·강좌 단위의 고유 제약을 둔다.

운영 Neon에는 적용하지 않았다. 이전 버전의 임시 미리보기 DB는 새 정의와 다르므로 재생성이 필요하다. 실제 공유 DB에 이전 버전을 적용한 적이 있다면 이 파일을 다시 실행하는 대신 별도 후속 마이그레이션이 필요하다.

## 검증

백엔드 테스트는 작성·조회·삭제, 익명 응답, 수강 기록 소유권, 관리자·공용 강좌 예외, 추천도 범위, 수정 API 차단, 같은 교수 재수강 중복 차단·다른 교수 후기 작성 허용 및 삭제 후 재작성 차단, 강좌 삭제 정리를 확인한다.
