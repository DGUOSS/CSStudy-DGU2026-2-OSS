# 오개념 반례 실험실 로컬 데모

Windows PowerShell에서 저장소 루트의 `start_demo.ps1`을 실행한다. 백엔드 가상환경과 프런트엔드 패키지가 이미 설치돼 있어야 한다. 스크립트는 `backend/.venv/demo.db`만 사용하며, 실제 교안 PDF 10개가 로컬 `data/raw/basic-programming-kang/`에 있어야 한다. 운영 DB와 원본 교안 파일은 변경하지 않는다.

```powershell
.\start_demo.ps1
```

실행 결과에 학생·관리자 계정과 공통 비밀번호, 특정 문제 체험 주소가 나온다. 같은 정보는 Git에서 제외되는 `backend/.venv/demo-info.txt`에 저장된다.

1. 학생 계정으로 체험 주소에 로그인한다. 원본 문제에서 `[7]`을 고르면 승인된 확인 문제가 나온다.
2. 확인 문제에 답하면 첫 문제의 해설, 오개념 가능성 안내, 실제 교안 32쪽 근거를 볼 수 있다.
3. 강좌의 **숙련도** 탭에서 당시 답과 안내를 다시 볼 수 있다. 확인 문제 답은 숙련도 점수에 반영하지 않는다.
4. 관리자 계정으로 `/admin/misconception-probes`에 들어간다. 새 데모 DB에서는 승인된 문제 1개와 검토 대기 중인 초안 2개가 있다. 초안을 수정·승인하거나 새 초안을 직접 만들 수 있다. 카드의 **이 문제 체험하기** 링크로 원본 문제를 바로 열 수 있다.

데모 서버 종료:

```powershell
.\stop_demo.ps1
```

데모는 사람이 검토한 확인 문제를 사용하는 학습 흐름을 보여준다. AI 자동 초안 생성은 아직 연결하지 않았다.
다시 시작하면 데모 DB의 풀이·승인 기록은 유지되고 계정 비밀번호만 새로 발급된다.
