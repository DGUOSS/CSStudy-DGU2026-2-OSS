# 학사공지 연동

- 브랜치: feat/academic-notices (origin/main 기준, 강좌후기 브랜치와 별개)
- 메인 화면에서 수강 기록 유무와 관계없이 학사공지 표시.
- 학교 학사공지 첫 페이지에서 고정 공지와 일반 공지를 수집하고 ID로 중복 제거.
- 날짜 내림차순 5건 표시, 더 보기로 수집한 전체 목록 확인. 중요 공지는 배지 표시.
- 제목 선택 시 텍스트 본문 표시. 이미지·표 원형·첨부파일은 학교 원문 링크 제공.
- HTML을 화면에 삽입하지 않음. 스크립트 제거 후 React 텍스트로 렌더링.

## API 및 운영

- GET /api/v1/notices
- GET /api/v1/notices/{notice_id}: 현재 목록에 있는 양수 ID만 허용.
- 학교 도메인과 게시판 경로 고정, 외부 리다이렉트 따라가지 않음.
- 10분 프로세스 메모리 캐시, 동시 갱신 잠금, 요청 타임아웃 10초.
- 실패 시 1분 후 재시도. 최대 24시간 이내 캐시를 이전 데이터 표시와 함께 제공.
- 캐시가 없거나 오래되었으면 503과 원문 확인 안내.
- 요청 시 갱신하는 구조로 별도 정기 작업 없음. 인스턴스마다 별도 캐시.
- DB/Neon/마이그레이션 변경 없음. DB에 공지 본문 저장하지 않음.
- 학교 HTML 구조가 바뀌면 파서 수정 필요. 첨부파일 수집은 미지원.

## 검증

- 테스트: 목록 중복/모바일 라벨, 본문 스크립트 제거, 구조 변경, 캐시 만료/장애/재시도, API/ID 제한.
- 2026-11-17 실제 페이지: 중복 제거 목록 14건, 첫 공지 본문 846자 수집 확인.
- 백엔드 전체 테스트 45개 통과, Ruff 검사/포맷 통과.
- 프론트 타입 검사, lint, production build 통과. 브라우저 시각 검증은 별도 필요.

## 키워드 검색

- 검색창에서 Enter 또는 검색 버튼으로 제목+본문 검색. 공백 제거, 최대 100자.
- 학교 게시판 검색에 직접 연결하여 과거 공지도 탐색. 검색 결과는 페이지당 10건, 이전/다음 제공.
- 검색과 무관하게 학교가 내려주는 고정 공지는 제외하고 일반 검색 결과만 표시.
- 검색 결과 없음 표시, 초기화로 기본 목록 복귀. 본문 전환 시 검색어/페이지 문맥 유지.
- 두 API에 q 및 page 쿼리 추가. 목록 응답에 total, page, query 추가.
- 검색어와 페이지별 캐시, 성공/실패 캐시 각각 최대 128개.
- 테스트: 특수문자 URL 인코딩, 검색 조건·페이지 전달, 검색 결과 상세 조회, 고정 공지 제외, 빈 검색 결과, 입력 길이 및 페이지 검증.
