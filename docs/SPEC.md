# 기본 틀 명세

- 상태: 기본 틀 구현 완료 (2026-11-07)
- 근거: 11/06 지도교수 미팅, 11/06 팀 회의 결정

## 흐름
```
로그인 → 과목 선택 → 교수 선택 → 강좌 페이지
                                  ├ 문제 풀이: 챕터 선택 → 5문제씩 풀이 → 정답·해설·교안 근거 → 결과
                                  ├ 숙련도: 챕터별·개념별 '알고 있을 확률'
                                  ├ 자료: 교안·기출·시험 정보 PDF 목록과 올리기
                                  └ 강좌·시험 정보: 누구나 수정
```
- 없는 과목·강좌(교수)는 사용자가 **추가 요청**하고 관리자(`users.role = admin`)가 승인한다. 요청할 때 교안 PDF를 내거나 '교안 없음'을 고른다.
  - 승인하면 과목·교수·강좌를 만들고(있으면 그대로 쓰고), 교안이 있으면 아래 판 관리 규칙으로 자료에 붙인다. 관리자는 승인하면서 과목명·교수명 표기를 고칠 수 있다.
  - 이미 있는 강좌를 요청하면 거절(409)하고 그 강좌를 알려 준다. 같은 과목·교수의 대기 중 요청이 있으면 새로 만들지 않는다.
  - 과목·강좌를 바로 만드는 `POST /subjects`, `POST /courses`는 관리자 전용이다.
- 관리자 화면(`/admin/courses`): 과목·강좌를 교안과 함께 바로 만들고, 기존 과목·강좌·교안(옛 판 포함)을 고치거나 지운다. `/admin/requests`: 추가 요청 승인·반려.
- 자료는 개인이 아니라 강좌 공용이다.

## 규칙
**문제 고르기** (`GET /chapters/{id}/problems`)
1. 아직 한 번도 안 나온 개념이 들어간 문제
2. 아직 안 푼 문제
3. 숙련도가 낮은 개념의 문제

한 번에 5문제를 고를 때도 안 나온 개념이 골고루 들어가게 한 문제씩 고른다.

**숙련도** (BKT, `features/mastery/bkt.py`)
- 개념마다 '알고 있을 확률'을 풀이 결과로 갱신한다. 문제에 개념이 여러 개면 모두 같은 결과로 갱신한다.
- 파라미터는 기본값(처음 알 확률 0.2, 배울 확률 0.15, 찍어서 맞힐 확률 0.25, 실수 0.1)으로 시작한다. 한 개념에 전체 풀이 기록이 40개 이상 쌓이면 pyBKT로 학습한 값을 쓴다.
- FSRS 복습 날짜는 쓰지 않는다(11/06 팀 결정).

**자료 올리기**
- PDF만, 30MB 이하. 쪽별 텍스트를 뽑아 DB에 저장한다. 원본 파일은 저장하지 않는다.
- 모든 쪽에 반복되는 머리글(교수명, 학교명 등)은 텍스트에서 뺀다.

**자료 판 관리** (`features/materials/versioning.py`)
- 교수마다 교안 구성이 달라서(주차별 파일, 학기 전체 파일 하나, 양식 없는 문서) 파일명·주차·양식이 아니라 **쪽 내용**으로 판단한다.
- 새 자료의 쪽마다 같은 강좌·같은 종류 최신판들의 모든 쪽과 비교한다(글자 3-gram 유사도). 같음 ≥ 0.9, 수정됨 ≥ 0.5, 그 아래는 새 내용.
- 모든 쪽이 '같음'이면 등록하지 않는다(중복, 200).
- 기존 자료의 쪽 70% 이상이 새 자료에 들어 있으면 그 자료를 옛 판으로 돌리고 새 자료가 대체한다. 주차 파일 여러 개를 큰 파일 하나로 올리면 여러 개가 함께 대체된다.
- 큰 교안의 일부만 고친 파일은 대체하지 않고 새 자료로 붙는다.
- 근거 문장이 새 자료에 있는 문제는 근거 쪽을 새 자료로 옮긴다. 옛 판은 지우지 않아서 옛 링크도 동작한다.
- 자료 목록은 최신판만 보여 준다(`?all_versions=true`면 옛 판까지).
- 한계: 글자 비교라서 같은 내용을 완전히 다른 말로 다시 쓴 교안은 '새 내용'으로 본다.

## 샘플 데이터
- 강동현 교수님 기초프로그래밍(CSC2001) 2~17장, 16챕터, 개념 45개, 샘플 문제 62개 (`data/seed/basic-programming-kang.json`)
- 문제마다 근거가 되는 교안 문장을 원문 그대로 넣었다. `scripts/seed.py`가 교안 PDF에서 그 문장의 쪽을 찾아 연결하고, 못 찾으면 실패한다.
- 문제는 사람이 교안을 보고 쓴 것이다. 실제 기출이 아니며 화면에 '샘플 문제'로 표시된다.

## API (`/api/v1`)
| 메서드 | 경로 | 로그인 | 설명 |
|---|---|---|---|
| POST | /auth/signup, /auth/login, /auth/logout | - | 쿠키(httpOnly) 로그인 |
| GET | /auth/me | 필요 | 내 정보 |
| GET·POST | /subjects | POST는 관리자 | 과목 목록·추가 |
| GET | /subjects/{id}/courses | - | 과목의 강좌(교수) 목록 |
| POST | /courses | 관리자 | 강좌 추가 (교수 이름으로) |
| GET·PATCH | /courses/{id} | PATCH만 | 강좌 정보·시험 정보 |
| GET·POST | /courses/{id}/materials | POST만 | 자료 목록(최신판)·PDF 올리기(판 관리) |
| GET | /materials/{id}/pages/{page} | - | 자료 한 쪽의 텍스트 |
| GET | /courses/{id}/chapters | - | 챕터·개념·문제 수 |
| GET | /chapters/{id}/problems?count=5 | 필요 | 다음 문제 (정답 제외) |
| POST | /problems/{id}/attempts | 필요 | 채점, 해설, 근거, 숙련도 변화 |
| GET | /courses/{id}/mastery | 필요 | 개념별 숙련도 |
| POST | /course-requests | 필요 | 과목·강좌 추가 요청 (form, 교안 PDF는 선택) |
| GET | /course-requests/mine | 필요 | 내 요청과 처리 상태 |
| GET | /admin/course-requests?status= | 관리자 | 요청 목록 |
| POST | /admin/course-requests/{id}/approve, /reject | 관리자 | 승인(이름 수정 가능), 반려(사유 필수) |
| POST | /admin/courses | 관리자 | 과목·교수·강좌 만들기(있으면 그대로) + 자료 PDF 여러 개 (판 관리 적용) |
| PATCH·DELETE | /admin/subjects/{id} | 관리자 | 과목명·학수번호 수정, 삭제(강좌가 없을 때만) |
| PATCH·DELETE | /admin/courses/{id} | 관리자 | 교수명 수정, 삭제(챕터·문제가 없을 때만, 자료도 함께 삭제) |
| PATCH·DELETE | /admin/materials/{id} | 관리자 | 제목·종류 수정, 삭제(최신판을 지우면 이전 판이 다시 최신판, 문제 근거는 남은 자료에서 다시 찾음) |

전체 명세는 서버 실행 후 http://localhost:8000/docs
