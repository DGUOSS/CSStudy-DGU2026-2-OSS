# 자동 문제 보충

## 동작

퀴즈 문제 조회와 답안 제출 뒤, 해당 사용자가 강좌에서 아직 풀지 않은
객관식 문제가 2개 이하이면 백그라운드에서 5개 생성을 시도한다.
생성이 끝난 문제는 다음 문제 조회부터 보인다. 이미 풀었던 문제는
미풀이 수에서 한 번만 제외한다.

`feat/question-generator`의 `question-ai/` 원본을 가져왔다.
사이트에서는 그 브랜치의 출제자 → 규칙 검사 → 정답을 숨긴 풀이자 →
검토자 단계를 `backend/app/qgen/`에 맞게 이식했다. 사이트는 교안을
파일이 아닌 `Material.pages`에 저장하므로, 이식한 코드는 DB의
교안 쪽을 출제 근거로 사용한다.

검토를 통과하고 교안의 실제 문장을 근거로 제시한 문항만
`Problem(origin="llm")`으로 저장한다. 중복된 문제 문장은 건너뛴다.
강좌에 챕터나 읽을 수 있는 교안이 없으면 생성을 건너뛴다.

## 설정

백엔드의 `ANTHROPIC_API_KEY`가 필요하다. 없으면 자동 생성은 실행되지
않는다. 생성 모델은 `QGEN_MODEL`로 바꿀 수 있으며 기본값은
`claude-haiku-5-5`다.

생성은 현재 Render 설정의 단일 서버 프로세스에서 강좌별 잠금으로
중복 실행을 막는다. 여러 서버 프로세스로 확장할 경우에는 DB 기반
작업 잠금으로 바꿔야 한다.
