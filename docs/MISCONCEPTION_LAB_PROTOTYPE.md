# 오개념 반례 실험실 시범

`/lab/misconception`에서 기초프로그래밍 샘플 문제의 `printf("[%03d]", 7)` 사례를 체험한다.

## 범위

- 답과 확신도 선택 → 숫자를 바꾼 반례 문제 → 두 답 비교와 교안 근거 표시
- 샘플 데이터의 검토된 문장과 정답을 사용한다. AI 호출은 없다.
- 사용자 답은 브라우저 화면에만 유지한다. API, DB, 숙련도, 기존 문제 풀이는 변경하지 않는다.
- 저장소에 원본 PDF가 없으므로 페이지 번호와 PDF 열기는 제공하지 않는다.

## 다음 단계

실제 강좌에 연결하려면 오답 선택지와 오개념의 관계, 반례 문제, 검토 상태, 근거 자료·쪽수를 저장하는 모델과 API가 필요하다. 오답 한 번만으로 오개념을 확정하지 않고 반례에 대한 답도 확인해야 한다. AI 생성은 초안에만 사용하고 검토된 반례만 사용자에게 보여 준다.
