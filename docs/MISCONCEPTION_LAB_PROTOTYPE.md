# 오개념 반례 실험실 시범

`/lab/misconception`에서 기초프로그래밍 샘플 문제의 `printf("[%03d]", 7)` 사례를 체험한다.

## 범위

- 답과 확신도 선택 → 선택한 오답에 맞춘 확인 문제 → 두 답을 종합한 신중한 안내 → 짧은 복습 문제
- 바탕화면의 실제 `week2.pdf` 32쪽에 나온 `%03d`, `%-3d` 규칙과 `1, 20, 300` 예제를 바탕으로 만든 고정 예시를 사용한다. AI 호출은 없다.
- 사용자 답은 브라우저 화면에만 유지한다. API, DB, 숙련도, 기존 문제 풀이는 변경하지 않는다.
- 교안의 근거 문장과 32쪽을 표시한다. PDF 원본 열기는 아직 연결되지 않았다.
- 복습 문제는 설명을 본 뒤 푸는 연습으로, 진단 결과에는 반영하지 않는다.

## 교안 검증

바탕화면 `교안 테스트 파일`의 PDF 10개를 로컬 `data/raw/basic-programming-kang/`에 복사해 대조했다. 이 폴더는 Git에서 제외된다. 시드의 문제·확인 문제 근거 문장 65개가 모두 해당 교안에서 발견되었다. 현재 실험실 사례의 근거 문장 세 개는 모두 `week2.pdf` 32쪽에 있다.

## 저장과 관리자 검토

오답 선택지별 오개념 가설·확인 문제·해설·교안 근거를 저장하는 `misconception_probes` 테이블을 추가했다. 기초프로그래밍 `printf("[%03d]", 7)` 샘플 문제의 오답 세 개에는 교안 32쪽 근거를 대조한 시드 초안을 넣는다. 기존 DB에 이미 문제가 있어도 시드를 다시 실행하면 확인 문제를 추가하며, 중복 생성하지 않는다. 시드 항목은 `draft`이므로 학생에게 노출하기 전에 관리자 검토가 필요하다.

관리자는 `/admin/misconception-probes`에서 원본 문제·학생이 고른 오답·오개념 가설·확인 문제·정답·해설·교안 근거를 함께 본다. 내용을 수정하면 초안으로 저장되며 기존 승인은 취소된다. 승인할 때 같은 강좌의 최신 승인 교안에서 지정한 쪽과 근거 문장이 실제로 일치하는지 검사한다. 승인 취소도 가능하다. API는 관리자 권한을 검사한다.

## 다음 단계

승인된 확인 문제만 실제 강좌 풀이에 연결한다. 현재 `/lab/misconception`은 고정 예시이므로 관리자 승인 결과가 이 화면에 반영되지는 않는다. 오답 한 번만으로 오개념을 확정하지 않고 확인 문제의 답도 본다. AI 생성은 초안에만 사용하고 검토된 반례만 사용자에게 보여 준다.
