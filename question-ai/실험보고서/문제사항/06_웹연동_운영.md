## W-01. 웹(백엔드)은 출제 프로필이 고정값 — **팀 논의 필요**
- **현상**: `backend/app/features/problems/generation.py`는 analyst를 부르지 않고 코드에 고정된 프로필 사용
  - 객관식 100%, 난이도 "보통", 세부 수준 "중간", 반복 패턴·말투 예시·강조 주제 비움, notes = 챕터 제목
  - planner 대신 코드(`plan_items`)가 개념 목록을 돌아가며 계획
  - 기출 말투는 `exam_style_examples` 3000자를 generator에 전달
- **영향**: 사용자·과목별 출제 경향이 웹 생성에는 반영되지 않음
- **근거**: 2026-11-21 대화 (팀원 질문)

## W-02. 백엔드가 question-ai 예전 버전에 고정 — **참고**
- **현상**: `backend/pyproject.toml`의 qgen이 `rev = 13bffc2`(패키징 수정 #20)로 고정. 11-20·11-21 변경(제목, M3, 베끼기 검사)은 반영 안 됨
- **주의**: 백엔드가 쓰는 qgen 부분(`checks.run`, `Retriever`, `format_chunks`, `chunk_pages`, `Page`, 스키마, `render_prompt`)은 사용법을 바꾸지 않게 유지 중. 새 필드는 모두 기본값 있음, reviewer 기출 예시는 프롬프트 파일에 빈칸을 만들지 않고 코드에서 붙임
- **근거**: 2026-11-21 확인

## W-03. 웹 연결 시 맞춰야 할 차이 — **팀원이 구현 (확인 필요)**
- **현상 (11-19 기준)**: 입력이 파일 → DB 글자, 결과가 파일 → 함수 반환값, 선지 5개 → 4개, `answer` "3" → `answer_index` 2, 생성기에 없는 `evidence`·`concepts`, 생성 4~7분 → 백그라운드 작업
- **현재**: 팀원이 main에 백엔드 래퍼를 합침 ("wrap qgen in backend", PR #19~#21). 출제 → 규칙검사 → 풀이 → 검토 순서를 사이트의 Claude 호출로 실행
- **근거**: 11-19 보고서 "웹 연결 준비", main 커밋 `65fd2b0`

## W-04. 의존성 충돌 가능성 — **확인 필요**
